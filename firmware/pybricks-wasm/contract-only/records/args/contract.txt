Behavior contract derived from caller use and documented argument-parser APIs:
1. Supported statement forms, each ending in semicolon:
 PB_PARSE_ARGS_FUNCTION(n_args, pos_args, kw_args, descriptors...);
 PB_PARSE_ARGS_METHOD(n_args, pos_args, kw_args, TYPE, INSTANCE_NAME, descriptors...);
 PB_PARSE_ARGS_METHOD_SKIP_SELF(n_args, pos_args, kw_args, descriptors...);
 PB_PARSE_ARGS_CLASS(n_args, n_kw, args, descriptors...);
 Their first parameters may be parenthesized C expressions. INSTANCE_NAME is an identifier and is not necessarily self. TYPE is a C type spelling. Descriptor order determines positional argument order. At least one descriptor is supplied; support arbitrarily many for conversion rather than a preprocessor fixed maximum.
2. Descriptors: PB_ARG_REQUIRED(name), PB_ARG_DEFAULT_INT(name, expr), PB_ARG_DEFAULT_OBJ(name, object_symbol), PB_ARG_DEFAULT_QSTR(name, unquoted_qstr_token), PB_ARG_DEFAULT_TRUE(name), PB_ARG_DEFAULT_FALSE(name), PB_ARG_DEFAULT_NONE(name). Argument names are identifiers. Integer expressions can include enum constants, parentheses, operators and nested calls. OBJ receives an object symbol whose address supplies the default. QSTR receives an unquoted token. Never C-preprocess these names.
3. Each invocation must declare static const mp_arg_t allowed_args[] in the enclosing function scope, an mp_arg_val_t parsed_args[] of the same length, and assignable mp_obj_t variables named <name>_in. Caller code may subsequently use allowed_args and parsed_args, and CLASS's mp_map_t kw_args. Do not hide these declarations in a nested block. All arguments use MP_ARG_OBJ, including integer/bool defaults. REQUIRED also has MP_ARG_REQUIRED. Required default is unused by the parser and must be initialized to a null object.
4. The declared table has fields qst (MP_QSTR_<name>), flags, defval (union member u_rom_obj). Public MicroPython ROM value constructors are MP_ROM_INT(expr), MP_ROM_PTR(pointer), MP_ROM_QSTR(qstr), MP_ROM_TRUE, MP_ROM_FALSE, MP_ROM_NONE. MP_ROM_PTR(NULL) supplies an unused null default. ROM constructors may expand to braced comma-separated initializers, so emitted C must support that without preprocessor iteration.
5. Public API contracts/types:
 typedef struct { qstr qst; mp_uint_t flags; mp_arg_val_t defval; } mp_arg_t;
 mp_arg_val_t has u_obj and u_rom_obj union members.
 void mp_arg_parse_all(size_t n_pos, const mp_obj_t *pos, mp_map_t *keywords, size_t n_allowed, const mp_arg_t *allowed, mp_arg_val_t *out);
 void mp_map_init_fixed_table(mp_map_t *map, size_t n_keyword_pairs, const mp_obj_t *pairs);
 MP_OBJ_TO_PTR(object) converts an instance to its C pointer.
 MP_ARRAY_SIZE(array) returns element count.
6. FUNCTION passes n_args, pos_args, kw_args directly to mp_arg_parse_all. METHOD parses n_args-1 and pos_args+1 (the leading instance is excluded) and declares TYPE *INSTANCE_NAME from pos_args[0]. Its _in variables come from the parsed result in descriptor order. SKIP_SELF performs the same exclusion without declaring/converting an instance. CLASS constructs mp_map_t kw_args from the n_kw name/value pairs beginning at args+n_args and parses n_args positional entries with that map. Preserve native MicroPython behavior for missing/extra/duplicate/unknown arguments by delegating to the API rather than recreating validation.
7. PB_PARSE_ARGS_METHOD_ALL_NONE() is an expression used after parsing. Replace it with a call to the existing MIT API pb_obj_parsed_args_all_none(parsed_args, MP_ARRAY_SIZE(parsed_args)), which returns whether every parsed object equals None, excluding any instance.
8. Remove real #include directives for pybricks/util_mp/pb_kwarg_helper.h (angle brackets or quotes). Supply explicit includes for py/runtime.h and pybricks/util_mp/pb_obj_helper.h as needed; no replacement header with the removed basename may be created. Include order is otherwise unchanged. All removed dependency identifiers in live code must be gone. Mentions in comments/strings must remain untouched.
9. Use lexical awareness: comments and C string/character literals are not code. Handle balanced (), {}, [] and nested commas when splitting arguments. Do not change examples in comments, string content or macros in inactive commented text. Fail with named file/line errors on unsupported PB_PARSE_ARGS_ or PB_ARG_ invocations in code; never silently partially translate. Do not parse implementation definitions of those macros; they are excluded inputs.
10. Output must be deterministic and idempotent: a second conversion of generated files needs no further changes. A failed conversion must not leave an output presented as complete. Keep unrelated source unchanged; the converter may only remove the specified include and replace supported invocations, plus add necessary includes. Guard path traversal/symlink escapes.
