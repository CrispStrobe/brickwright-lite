Pybricks MicroPython, compiled to WebAssembly for the Brickwright SPIKE Prime simulator
(static/pybricks-sim/pybricks-hub.wasm). Built from pybricks-micropython v4.0.1,
commit 4104553405decb0384bcfb030fbfcb4b5a9854cc, and its MicroPython submodule,
commit 13580b6ad057173f62e8b2363e01d6851bcc6699. Recipe: build-pybricks-wasm.sh.

This build contains NO BTstack, no other Bluetooth stack, no vendor HAL and no
file from MicroPython's lib/ directory; build-pybricks-wasm.sh checks the licence
of every file the compiler read (firmware/pybricks-wasm/licence_gate.py).
No file compiled into this build carries share-alike terms. Upstream's
pybricks/util_mp/pb_kwarg_helper.h (tagged MIT AND CC-BY-SA-4.0) is replaced
by a clean-room MIT rewrite by The Pybricks Authors. The one function of
lib/pbio/src/int_math.c adapted from a share-alike source,
pbio_int_math_mult_then_div(), is replaced by a Brickwright stand-in
(BSD-3-Clause, Copyright (c) 2026 Brickwright contributors).
