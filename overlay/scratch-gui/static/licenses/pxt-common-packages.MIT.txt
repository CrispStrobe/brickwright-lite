Microsoft MakeCode code and data compiled into Lite's Arcade runtime (task E1):

- pxt-common-packages (https://github.com/microsoft/pxt-common-packages), as bundled
  in pxt-arcade 4.2.1: the simulator image algorithms in
  overlay/scratch-vm/src/extensions/crispstrobe/arcade/image-pxt.js, the text layout
  and speech rendering (game/renderText.ts, game/spritesay.ts) in speech-pxt.js, and
  font8 (screen/text.ts) in speech-fonts.json;
- pxt-arcade (https://github.com/microsoft/pxt-arcade) 4.2.1: the built-in image table
  (device/*.jres) in overlay/scratch-gui/src/lib/bw-makecode/arcade-builtin-images.js.
