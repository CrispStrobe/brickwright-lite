# Shared Image Array source transport

## Observed gap

The current exporter represents a shared frame Image with a source Array of
image literals. Eager source lowering turns that nonempty initializer into
ordinary Array construction before the later frame resource recognizer sees
it. A subsequent export retains those connected constructions and emits another
resource backing Array. An observed conversion added 204 connected blocks;
that original growth and its separate local, callback and startup causes must
remain retained. This contract addresses only the shared frame transport part.

A generated variable name, repeated pixels or a declared `Image[]` type cannot
prove that an Array is a resource. Preserve every current body, allocation,
Image alias, mutation, diagnostic and partial result.

## Supported proof domain

Prepare a source plan before eager aggregate staging. Derive its authority from
actual executable nodes, lexical bindings, initialization and all writers.
Initially admit only a bounded ordinary top-level declaration with one
nonempty literal Array of fully decoded, proved builtin Image literals. Each
initializer executes once per program entry. Prove the actual builtin tag and
numeric operations; shadowed, written, escaped or unknown configured effects
cannot acquire resource authority through their spelling.

Every use must be an admitted frame selection on that same binding or an
independently proved immutable alias. Prove initialization dominance and the
exact current caller, registration and capture paths that can execute a use.
Keep literal index/count and wrapping semantics exact. Dynamic or effectful
indices require their own existing producer and evaluation-order proof;
otherwise retain ordinary lowering and its diagnostics.

The Array itself must remain unexposed. Whole-Array arguments, returns, stored
references, comparisons, length or shape observations, index writes, deletion,
mutating methods and unknown receiver effects disqualify this transport proof.
Do not erase such operations to qualify a resource. An Image selected from an
admitted resource may retain its own supported aliases and mutations; those do
not authorize mutation or escape of the backing Array.

A function-local, loop, conditional or repeatedly evaluated initializer cannot
become one global cached resource. Preserve fresh construction each time its
original position executes. Unknown initialization order, reads before the
initializer, reentry or exposed allocation identity keep ordinary semantics.
Shared or cyclic executable syntax, stale nodes and ambiguous bindings refuse.

## One current plan across lowering and resources

Use one private, current source plan for staging and resource emission. A
caller-supplied record, annotation or boolean is not authority. Bind the plan
to the actual Program, declaration, literal elements, lexical aliases and
physical consuming nodes. Neither stage may renew a stale proof or accept a
resource chosen only by a generated name.

The source resource path consumes only that proved transport. If a later route
cannot consume it, retain correct ordinary lowering and all unsupported
results. Generic or partially supported programs must not receive an unlowered
ordinary Array merely because a specialized route was considered earlier.
Do not allocate artwork for nonemitted bodies, create an accidental actor or
silently omit an unsupported body.

One actual admitted initializer defines one resource identity. Proved aliases
use that same identity; distinct initializers with identical pixels remain
distinct. Repeated selected Image reads must observe the same Image and its
mutations. Clones stay fresh at their original evaluation position. Preserve
current resource ownership, artwork edits, presence checks and Stop, restart,
load and disposal behavior. This work does not change runtime cache lifetimes.

The existing source representation may then import back into the same current
resource operation without adding another backing construction. Older actual
Array operations remain current operations. Do not prune them, strip generated
prefixes, restore an earlier source body or substitute a retained original.
