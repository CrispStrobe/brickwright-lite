## Buzzer documentation

The [OpenRoberta iOS LEGO SDK output codec](https://github.com/OpenRoberta/app-ios/blob/6639a2d3d0e47fcfb69b138bb4790b3ab2ff5d3c/LEGODevice/LEGODevice/LEOutputCommand.m) encodes piezo command 02 with a four-byte frequency/duration payload and command 03 to stop. Its [tone player](https://github.com/OpenRoberta/app-ios/blob/6639a2d3d0e47fcfb69b138bb4790b3ab2ff5d3c/LEGODevice/LEGODevice/LEPiezoTonePlayer.m) forwards frequency and milliseconds; no additional enable sequence was found in that path. These match the tested protocol, but do not prove this clone contains a functioning buzzer. Long notes and write-without-response were already tried without a confirmed tone.

[Pybricks maintainers explain that WeDo 2 cannot run Pybricks firmware](https://github.com/orgs/pybricks/discussions/658); remote control needs another library. WeDo accessory identifiers in Pybricks sources do not establish a supported WeDo-hub buzzer implementation.
