# Arcade generated helper recognition maintenance

Status: proposed ownership contract. Implementation waits for normal claim merge.
The reviewed source composition and its full foundation qualification are
prerequisites for adoption. This document does not assert that the public main
branch already contains every current source fence or passes these gates.

## Scope

Maintain import recognition of existing exporter-generated named Array
parse/JSON/access helpers and existing Scratch stop/run-token machinery. The
output remains the existing named Array/value and stop operations. Preserve
ordinary source, full helper bodies, argument evaluation, state changes,
aliases, supported value domains, diagnostics and partial conversion results.

The source paths are
`overlay/scratch-gui/src/lib/bw-makecode/arcade-translate.js`,
`named-array-item-helpers.js`, their coordinated parser-option or source-proof
helper, focused existing/new tests and this contract. Coordinate shared importer
and parser interfaces with their owners. Read-only exporter/runtime source
provides the canonical helper protocol; this claim changes neither its emitted
runtime behavior nor the engine ABI, scheduling, dependencies or pins.

## Canonical parsing

Canonical templates and actual input must use the same explicit admitted parser
context, including parentheses, conditional default prologues, retained original
default-signature provenance and any selected callable metadata. Cache templates
separately for distinct supported contexts. Preserve direct helper API variants
through explicit profiles and real parser controls. Unsupported or unknown
contexts retain a refusal; they do not borrow a partial match.

Do not strip arbitrary metadata, loosen a whole-body comparison, normalize an
unknown descriptor to absence, or add signature-default eligibility to make a
generated helper match. Metadata recovery alone grants no Number, Array, object,
reference, callable or SDK producer authority.

## Current declaration and use proof

Before replacing a call or removing a declaration, establish its actual unique
lexical declaration, complete canonical body, parameter/default shape and every
relevant use. The proof must cover duplicate declarations, function/parameter/
block shadowing, all writes, reassignment, extraction, escape, aliases and
currentness across callbacks or rewrites. A helper name, prefix, arity, caller
count or matching first statement is insufficient.

A transformed call keeps actual argument evaluation order and count. Unmatched
calls, extra statements, foreign storage effects and ambiguous neighboring code
must survive unchanged or produce an explicit existing refusal. They must never
be pruned as presumed generated scaffolding.

## Stop protocol

Recognize the complete `_tok`, `_dead`, applicable stop-other helpers and the
whole exporter-generated stop-all body with their actual binding relationships.
Bind token/mark/kept storage and every generated guard or assignment to that
protocol. A same-prefix user function containing additional effects is user
code. Generated clone destruction, sound stopping and speech clearing require
complete current recipe/operand proof before their containing helper can be
replaced; a first token assignment does not certify the remaining body.

Stop-all, stop-other, clone and later-hat behavior retain their existing runtime
semantics. Do not delete general assignments or returns by spelling, invent
source ownership from generated names, or change cancellation/frame policy to
obtain a roundtrip pass.

## Exclusions

Generic optional/default parameter semantics, new reference/value producers,
annotation authority, helper execution as proof, arbitrary user function
inlining and nonempty Array staging are outside this claim. In particular, an
ordinary function returning a default value requires its own actual-call and
completion evidence; successful generated JSON recognition does not qualify
that separate case.

## Qualification

Keep original failure evidence and every original behavioral assertion. Add
actual-parser controls for supported contexts and direct API variants, canonical
positive helpers, renamed valid helpers, metadata/default/body drift, extra
side effects, duplicate declarations, shadowed or written callees, extracted
references, escape, foreign storage writes and argument effects exactly once.
Stop controls cover whole-body drift, lifecycle and normal stop-all/stop-other
behavior, including later hats and clones where admitted.

Retain actual stage returns, diagnostic channels and partial output before
judgment. Focused source controls do not replace current public import, native
execution, Code, same/fresh saved project, current export and matching original
SDK reimport qualification. Visible authoring and save/reopen gates remain
separate. No focused test count promotes a corpus case or changes its criteria.
