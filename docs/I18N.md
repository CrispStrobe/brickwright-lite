# Translating strings in this tree

Three mechanisms exist here. Picking the wrong one is how strings go missing,
so pick by **who owns the component**, not by what is nearest to hand.

| Where the component lives | Use | Example |
|---|---|---|
| scratch-gui's own tree (`stage-header`, `menu-bar`, …) | `react-intl`: `defineMessages` + `intl.formatMessage` | `components/stage-header/stage-header.jsx` |
| Ours (`tw-pseudocode`, `gui/pane-*`) | a local table + `makeT` from `lib/bw-i18n.js`, with the locale from `state.locales.locale` | `components/tw-pseudocode/circuit-tab.jsx` |
| A module with no props at all (pure lib) | a shared table for the whole feature | `lib/bw-fpga/l10n.js` |

**Do not move scratch-gui's strings into a local table.** Their messages go
through `scratch-l10n` and the upstream translation pipeline; a local table
would cut them off from the people who translate them.

## Rules that are enforced

`test/i18n-no-hardcoded-strings.test.mjs` walks every `.jsx` under
`components/` and `containers/` and fails on a hardcoded `title`,
`aria-label` or `placeholder`. These are the strings that go missing, because
they render only on hover or to a screen reader — clicking through the UI never
shows them.

`test/fpga-i18n.test.mjs` additionally holds the FPGA learning path to:

- every locale carries **every** key (a half-done translation renders English
  and looks finished);
- a locale more than 20% identical to English is refused (catches a
  "translation" that copied the table);
- **no prose literal** in `challenges.js`, `grader.js`, `logic-ic-circuit.js`.

## Plurals

There is no plural **suffix** anywhere, deliberately. Appending an English
`"s"` to a shared template produced *"4 Eingangskombination**s**"* — the bug
that makes a translation look finished while reading as nonsense.

Write both forms out per locale and use `makeTn`:

```js
'count.inputs.one':   '1 input',      // de: '1 Eingang'
'count.inputs.other': '{n} inputs',   // de: '{n} Eingänge'
```

## What is NOT a user-facing string

- Console diagnostics (`[brickwright] …`) — nobody reads a log in translation,
  and hiding them from the developer who needs them helps no one.
- Thrown developer errors (`throw new TypeError('… needs a live circuit …')`).
- Part numbers (`74HC86 Quad XOR`) and brand names (`Scratch`) — the same in
  every language.
