## TestFlight app description — en-US

Brickwright turns your Mac into a hands-on lab for code, circuits, and machines.

Build on a virtual breadboard, inspect the matching schematic, run the circuit,
and measure what happens. Use a multimeter, function generator, oscilloscope,
sweep tools, and design checks that point out common wiring mistakes.

Program with Scratch-style blocks and Brickwright Code, work with Python,
JavaScript, and C representations where supported, and see how a project reaches
the machine. Pause, step, set breakpoints, watch values, and inspect pins,
registers, memory, serial output, and instruction traces.

Included English and German guided lessons start with closed paths, polarity,
Ohm's law, and safe component use, then progress through measurement, scope
triggering, RC timing, debugging, controllers, and computer architecture. Lessons
ask you to predict, build, run, observe, and explain in the live editor.

The native app works offline, opens and saves .sb3 projects, and connects directly
to supported LEGO SPIKE, Boost, WeDo, and Powered Up hubs over Bluetooth.

Brickwright Lite is free and open source. It combines the last permissively
licensed Scratch codebase with Brickwright's own editors, circuit engine,
simulators, debuggers, lessons, device runtimes, and native shell. It is not a
TurboWarp fork and is not affiliated with Scratch, MIT, LEGO, STC, Arduino, or
Raspberry Pi.

## App Store description — en-US

BUILD CIRCUITS. PROGRAM MACHINES. SEE HOW THEY WORK.

Brickwright is an open-source studio for learning and creating with code,
electronics, simulation, and real devices.

BUILD AND MEASURE CIRCUITS
Place components on a virtual breadboard, wire them, and inspect the generated
schematic. Run the circuit and use a multimeter, function generator,
oscilloscope, sweeps, and design checks to turn invisible electrical behavior
into evidence you can inspect.

PROGRAM AT YOUR LEVEL
Start with Scratch-style blocks or Brickwright Code. Work with Python,
JavaScript, and C representations where the project supports them, while clear
labels distinguish editable source from generated views. One workspace keeps
the program, circuit, controls, and machine together.

DEBUG WITH EVIDENCE
Pause and step programs, set breakpoints, watch values, and inspect serial data,
pins, registers, memory, buses, and instruction traces. Emulated 8051/STC12,
AVR/Arduino, RP2040/Pico, 6502, and Z80 systems reveal what is happening below
the source code.

LEARN IN THE LIVE WORKSPACE
English and German guided lessons sit beside the editor instead of replacing
it. Begin with circuits and safe measurement, then progress through code,
debugging, interactive controls, signals, and computer architecture. Every
lesson asks you to make and test a prediction.

CONNECT REAL LEGO HARDWARE
Use the native Bluetooth connection with supported LEGO SPIKE, Boost, WeDo, and
Powered Up hubs. Explore motors and sensors in the same environment as your
blocks and code.

NATIVE, OFFLINE, AND OPEN
Work without a browser, open and save .sb3 projects, and keep the tools and
included examples available offline. Brickwright Lite is free and open source.
It combines permissively licensed Scratch components with Brickwright's own
editors, circuit engine, simulations, debuggers, lessons, device runtimes, and
native shell. It is not a TurboWarp fork.

Brickwright is not affiliated with or endorsed by Scratch, MIT, LEGO, STC,
Arduino, or Raspberry Pi. All trademarks belong to their owners.

## What to Test — 0.1.7 en-US

This build is mostly repairs. All seven lesson waves were reviewed against the
running app rather than read, and 38 of 72 lessons turned out to be teaching
something the bench could not show; 42 of them were revised. Several examples
could not do what they demonstrated.

Please test:
- **Saving.** File > Save to Computer. If it fails it now SAYS SO, with the
  reason, instead of doing nothing — please report the exact message. A saved
  project also now carries the Circuit, Code and Widgets tabs, not just the
  blocks: save a project that uses several tabs, load it on another device, and
  check all of it came back. Older project files still open normally.
- **Faceplates.** Open a2-faceplate-calculator, lego-hub-face, mb05-faceplate-calc
  and retro-console. Every control on these used to open disabled, so nothing
  responded to a tap. They should now be operable immediately.
- **Fading and PWM.** The Arduino fade examples declared their pins as plain
  outputs and so could only switch on and off. They should now fade smoothly.
- **The shift register.** 20-shift-register-binary lit no LEDs at all — its bit
  test was false even when the bit was set. All eight should now count.
- **Lessons.** Work through any lesson and check that what a checkpoint asks you
  to observe is actually observable on the bench it names. That is precisely what
  the review found wrong 38 times, and it is the report we most want.

Please report the exact example, device, and steps for anything that does not
respond, does not save, or asks you to observe something you cannot see.

## Beta App Review notes

No account or login is required. All core functionality is available without
external hardware: choose an included starter, open a guided lesson, switch among
program/circuit views, run or step the project, and inspect the circuit instruments
and debugger. Lessons are local content and progress is stored only on the device.

Bluetooth testing is optional and requires a compatible LEGO SPIKE, Boost, WeDo, or
Powered Up hub. Camera and microphone permissions are requested only when a project
uses those features. Brickwright Lite is based on permissively licensed Scratch
components plus original editors, circuit simulation, debugging, lessons, device
runtimes, and native-app code; it is not a TurboWarp fork.
