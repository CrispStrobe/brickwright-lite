# Named Array item values

Named Array `get` preserves Number, Boolean, String, null and undefined values. Plain aggregate objects use JSON text; actual native references retain their identity. String contents are values, including strings resembling JSON or handles.

The Arcade exporter reconstructs the scalar and aggregate branch with a complete generated helper. Reimport validates that complete body and its actual lexical binding, receiver, initializers and writers. Recognized registry creation and deletion use the existing named Array words. Exact push, set and insert helpers also use those words, preserving the existing legacy input parsing without converting parsed Array aggregates into new reference carriers.

Old JSON-only getter helpers retain their meaning. Names resembling helper names grant no authority. Unknown initializers, writers, receiver aliases, changed bindings and escaping registry arguments receive diagnostics. Nested local or function-scoped declarations sharing a registry name are conservatively refused; this slice does not reconstruct arbitrary nested lexical shadows. Export follows historical variable aliases across actual project owners and refuses opaque or native reference inputs, including typed source references whose native carrier is a String. This does not add reference domains or use handle spelling to classify literal strings.

Prototype-sensitive registry names remain refused by this export slice. Their native dictionary behavior needs separate qualification. Other unresolved primitive producers and dynamic text transports also remain conservative boundaries.

`getMulti` requests aggregate JSON in the native extension. `get2D` and `pop` preserve aggregate objects; this change does not alter those methods. A native control captures the actual extension instance owned by its VM and checks the distinction and object identity. It does not claim new authoring or export support for those methods.
