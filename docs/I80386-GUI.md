# Experimental 80386 AT in Circuits, Widgets, and Code

Open **Manage machines** from the Code tab. For a local disk, select a raw `.img`/`.ima`/`.bin` hard-disk image and click **Boot disk**. Optionally select a DOSBox `.conf` first. The importer reads a 386/486 CPU setting and `imgmount c ... -size 512,sectors,heads,cylinders`; it never executes `[autoexec]` commands. Without a config, the loader infers 4 heads and 17 sectors from the file size, up to 1024 cylinders. The image remains in this browser tab. A URL-based Machine Manager config is also supported; its HDD slot should name explicit CHS geometry. Media bytes are not saved to the project or machine library.

The boot path uses the bundled free Bochs BIOS and VGA option ROM, the experimental 386 AT, and its optional PS/2 mouse port. On boot, the VGA frame appears as a large interactive screen in the **Widgets** pane; the pane's **Full screen** button expands that screen to the display. Click the screen to focus it. IBM PC set-1 keyboard make/break codes, pointer movement, and left/right/middle button changes go to the running machine. Positive pointer `dy` means screen down. A separate keyboard widget, if declared, still works through its existing ASCII-to-scancode queue. The debugger screen remains available in the Circuits/Code dock.

The guest must enable PS/2 mouse reporting before pointer packets are accepted. Keyboard and pointer input are live; the experimental 386 target still refuses architectural checkpoint/replay. The browser may reserve keys such as Escape while in full-screen mode. The GUI does not bundle commercial DOS or Windows media, and a local file selection is not persisted across reloads.
