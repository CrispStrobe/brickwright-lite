Image is the actual input or an actual supported allocation, not a reconstructed

## Source and native authority

Annotations constrain accepted producers; they never create an Image. Prove
actual unshadowed SDK Image producers and all connected aliases and writers.
The qualified producer set is unshadowed `image.create` with finite literal
dimensions whose actual integer values are in the supported range, and clone
of an already proved Image. Literal-resource decoding and dynamic dimensions
remain separate producer requirements. Other producers, including
screen and Sprite image views, need their own explicit connected-producer and
alias proof before admission. Uninitialized, optional or mixed values remain
refusals unless the existing independent presence proof proves the actual read.
Keep lexical binding identity, evaluation order and initialization dominance.
Unknown neighboring bodies, opaque casts, overridden factories, local or formal
SDK shadowing, unsupported computed calls and captured writer channels refuse.

An Image signature is a distinct qualified SDK value domain. It does not make
Image an ordinary managed class, permit `new Image`, support SDK inheritance,
or make an authored class named Image authoritative. Do not widen Sprite,
Buffer, Font, arbitrary reference kinds, Function, Any or unknown domains.

Native validation requires the current extension, exact image service identity,
current runtime reference scope, and the actual live Image body owned by that
service. A codec reference alone supplies transport, not Image body authority.
Validate all typed field writes and reads and every supported constructor,
callback argument and result boundary. Generic substitutions remain local to
an invocation. Do not specialize a shared generic method from its first call.
Preserve the existing class frame issuer, actual receiver, capture cells,
current procedure graph, conditional result certificate and completion tickets.

Plain objects, bodyless carriers, fake or foreign IDs, stale references and
replaced services must refuse. Stop, restart, Load and dispose retain their
actual Image and callable lifetime rules. Observe pixel identity and mutation
through legitimate restart/reload; do not invent a new disposal or reset rule.
An owned mutation must remain visible through every live Image alias.
