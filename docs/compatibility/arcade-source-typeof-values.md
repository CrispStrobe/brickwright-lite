# Arcade source typeof values

Proposed scope under the source value and managed class lanes. Merge the
documentation claim before implementing the new authoring reporter.

## Concrete prerequisite

Named Arrays item reads must return scalar text without JSON quotation marks.
Their aggregate JSON APIs and legacy input parsing keep their own contracts.
The corrected Arcade export helper returns scalar values directly and serializes
raw object aggregates. A selected original execution matched the corrected
item values. Reimport exposed an existing converter omission: `typeof value`
became `value`, so an aggregate JSON result became an array reference.
That failure remains a qualification blocker.

Common MakeCode, EV3 and Calliope export use direct named array indexing and
inherit the common item contract. The new source type operation is scoped to
Arcade; their existing exporters remain separate owners.

## Owned implementation

- A synchronous source type service with an explicit native reporter and
  canonical producer word. Start the supplier from the qualified producer
  foundation, independently of unpublished callable source vocabulary.
- Arcade lowering and export of the actual `typeof` operation, preserving
  operand evaluation once, receiver/capture ownership and authored side effects.
- Actual editable block inputs, Code reconstruction, same and fresh VM SB3,
  strict selected original export and native reimport qualification.
- The E15 named-item export helper and affected regression controls, retaining
  JSON aggregates and input parsing without treating JSON-looking text as data.

## Type authority

Primitive results must follow the selected original runtime for numbers,
Booleans, strings, null and undefined, including special numbers and empty,
Unicode and JSON-looking strings. Array and object results require their
actual value or registered source allocation metadata. Native Sprite, Image,
managed class and other reference services require a qualified ownership
adapter and the actual SDK contract.

The first slice targets primitives and unambiguous owned Array, managed class,
Image and Buffer carriers. Native Sprite handles currently share a primitive
string representation. A string equal to a live handle must remain a string;
registry matching alone cannot distinguish it from the original Sprite object.
Sprite object typing, equality and coercion require a separately qualified
carrier migration that preserves canonical identity and existing aliases.
Ambiguous Sprite cases keep explicit refusals in this slice.

A reference kind label or token spelling cannot supply a source type. The
service must use current registered metadata or an owned underlying value.
Qualification must cover aliases, destroyed objects, scene changes, Stop,
restart and fresh project loading wherever those values are admitted. A stale
or unowned representation cannot acquire authority from persisted strings.

Selected original callable controls distinguish a noncapturing function label
(`function`) from a captured action (`object`). That distinction may be used
only through the actual qualified callable representation metadata. Callable
source admission and additional callable lifecycle behavior remain in their
existing lane. Missing metadata produces a named refusal.

## Startup and authoring API

Construct the source type service inside the existing Arcade extension startup.
It receives the current value codec and explicit ownership adapters for admitted
underlying values and registered representations. The reporter evaluates its
connected value input once and returns a String. It allocates no handles and
adds no source declaration or scheduler lifecycle of its own. Adapters must
validate their actual owner and generation before supplying representation
metadata; missing, changed or stale ownership produces a named diagnostic.

String return authority must remain visible in the source declaration inventory
and the actual reporter's export graph. A variable initialized with `typeof`
must keep its String declaration in native Code and the existing source startup
header through editing, saving, export and reimport. Preserve atomic scalar and
reference declaration prefixes and their original initialization order.

The standalone producer word starts from the qualified 380-word foundation.
Its source/runtime contract must qualify independently. The five unpublished
callable words can compose with it later as a six-word candidate after their
own strict metadata and source/export qualification; the type operation cannot
implicitly admit their callable source forms.

## Qualification and limits

Retain the first omission and reimport failures. Record exact selected original
inputs and compiler outputs from the compilation that actually executed.
Compare primitive and reference results, aggregate text, pointer identity and
side-effect order through native execution, Code, edited Blocks, saved projects,
original export and reimport. Include malformed metadata, foreign and stale
values, computed inputs and unsupported ownership controls.

The operation must use the existing source frame and managed procedure
boundaries. This scope adds no scheduler, physical frame phase, class designer
or independent board service. Feature controls do not promote retained packages
or claim complete game execution.

## Current implementation candidate

The canonical reporter is `arcade source type of {VALUE}`. Its String result
is independent of its operand's type in the declaration and export graphs.
The native service admits primitives and actual current Array, Image, Buffer
and managed class bodies. It refuses callable and other reference owners.
Sprite operands remain refused in source conversion and export; a literal
String equal to a live Sprite handle remains a String.

String operands require source provenance because native Sprite handles share
their carrier. The service binds the actual reporter from Scratch's current
cached operation using the identical argument object. It checks the active
runtime thread and its actual block container before trusting that operation.
Retained arguments from a killed thread, foreign containers and copied argument
objects cannot acquire authority. Global array writers and relevant aliases
are checked across original project targets; unresolved foreign mutations
produce a named refusal.

The entire original project input graph is captured at source startup,
including target/container identity, parent and top-level ownership metadata.
Editing that graph requires a new project start before reporter provenance
can be reused. This conservative restart boundary is
an editor limitation, not a claim of live source graph migration. Unknown
procedure, capture or member provenance remains refused.

Direct owned allocations, aliases and ordinary function results with proven
producers remain eligible. A field or method annotation alone cannot qualify
a managed member result: an `as any` write or return may carry another owner.
Unresolved member-result flow remains refused through variables and returns;
it does not widen the scalar or reference declaration domains.

The candidate has focused owner, lowering, export and mutation controls.
Complete source/original export, Code, edited Blocks, saved-project and E15
reimport qualification is still required before consumer adoption.
