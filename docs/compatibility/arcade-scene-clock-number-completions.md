## Physical completion

the original scene reporter. Existing before-input execution starts a private
per-thread command segment; the original cached reporter gets an empty-input
primitive loan. The source read supplies the actual current scene and raw finite
Number. Its real synchronous return must match that read before a private
completion receipt exists. Loan presence, public tags, copied arguments and a
Number-looking returned value alone cannot create one.

The current consumer must own its actual invocation, root/thread/container,
current complete cache and unique parent input holding that completed value.
A dormant reporter is only a structural obligation of another ordinary caller,
never a supplied completed value. Existing ordinary entry tickets bind checked
arguments; no new return, captured-cell or class-field authority is inferred.

Scene identity, the owned scene registry, existing scene-activation serial and
private project generations prevent scene push/pop ABA, Stop, restart, Load or
disposal from reviving a result. Reentering/resuming a command begins a fresh
segment. If a resumed input would need an expired clock completion, it refuses;
it does not reread the clock to invent a replacement. A child segment cannot
supply its receipt to a different parent caller.

Direct services retain the original `_state().elapsedMs || 0` behavior, including
historical fallbacks, without Number certification. Genuine undefined scene
initialization remains. Effectful accessor clock slots, nonfinite/text/unknown
reads and thrown or substituted returns cannot certify cached Number inputs.
The finite negative-zero result retains the original positive-zero fallback.
Neither validation nor a downstream consumer repeats the producer read.
