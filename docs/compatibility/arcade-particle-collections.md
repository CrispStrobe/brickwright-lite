# Native particle collections

The native particle host executes the retained MakeCode particle factories and
sources generated by `scripts/generate-arcade-particles.mjs`. PXT collections
have operations that JavaScript arrays do not provide directly.

The generator lowers reviewed collection calls through a module-local adapter.
Its AST transform preserves receiver and argument evaluation order and rejects a
changed callsite inventory. The retained sources contain one `removeAt` call in
`AshFactory`, and four `removeElement` calls in particle source/effect cleanup.
No Array prototype methods are installed. Seeded random selection, including
`FastRandom.pickRandom`, stays in the complete original compiled implementation.

The adapter follows [PXT's Array_ and RefCollection implementation](https://github.com/microsoft/pxt/blob/c40f412dc5bebb915a5891cd62fe956e198fb194/pxtsim/libgeneric.ts)
from PXT 13.2.1. `removeAt` checks the original bounds before removing a value;
invalid indices return `undefined` without mutation. Fractional indices use the
original JavaScript splice behavior after that bounds check. `removeElement`
removes the first matching reference and returns the simulator's numeric 1/0.
The helper adapts the particle host's local JavaScript-array storage; it does not
implement the original simulator's object allocation, reference counting or GC.
Its MIT notice is retained beside the source.

Focused tests:

```
node --import ./scripts/lib/register-gui-scope.mjs --test \
  test/makecode-arcade-particle-collections.test.mjs \
  test/makecode-arcade-particle-effects.test.mjs
```

Original compiler/simulator comparisons cover invalid and fractional indices,
empty collections, negative zero, removal results, AshFactory exhaustion with
single and multiple color counts, image clearing and ash-effect destruction.
The existing suite also checks particle rendering, cleanup and editable
conversion. These finite controls do not establish matching random particle
pixels, general collection compatibility or exact whole-game timing.
