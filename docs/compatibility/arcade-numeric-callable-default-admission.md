# Bounded numeric callable default admission

This proposed lane authorizes default conversion only after independent review
and qualification of the existing version 1 lexical bridge. The supplier ABI
has six callable operations. Codec transport alone never authorizes execution.

## Eligible source

A module factory has concrete numeric parameters and returns a zero-argument
Arrow with a numeric result. The Arrow captures mutable numeric factory-local
cells. Factory and Arrow bodies use straight-line numeric assignments and an
explicit final return. Alias calls preserve the same captured cells; separate
factory calls retain separate action identity. Names and packages supply no
eligibility authority.

A first typed numeric local may initialize to undefined only when a numeric
write dominates every read and capture. Later, repeated, parameter or captured
undefined writes remain refused. A structurally resolved single-return numeric
operator helper is eligible only when every actual call has concrete numeric,
side-effect-free operands; normalization preserves each operand once and in
source order. Defaults, optional parameters, control flow, nested owners,
ordinary FunctionExpression returns, unrelated callbacks, classes, generics and
receiver captures remain outside this lane.

## Export and editing

Default export must validate the actual versioned lexical graph, connected
variable identities and current editable procedure bodies. It must reconstruct
a genuine Arrow and numeric capture cells from those current blocks. Retained
original AST bodies, name guesses, wrapper records and forwarding thunks cannot
replace current body authority. The reconstructed source must pass the same
bounded source gate before default export is admitted. Invalid seals, missing
writes, edited signatures, foreign owners and malformed schemas remain explicit
refusals; a stable variable-ID rename remains valid.

## Required qualification

Keep actual selected-original input and executed binary receipts for the source
and edited export, and preserve their first failures. Current-source cached
checks must bind those exact bytes and the consumed SDK/helper guards without
replaying successful guests. Require renamed factory/parameter/local variants,
distinct increments, alias and separate-instance identity, current-body edits,
Code reparse, same/fresh SB3 reload, export/reimport, and generation/scene/Stop
refusals. Ordinary programs without this profile keep their existing path.
Unknown adjacent source and library diagnostics must remain visible.

This lane does not admit callable source typeof, stored class callbacks,
generic higher-order APIs or host registration. Those interfaces require their
own owner and qualification. Hosted GUI authoring and whole-game execution
remain separate acceptance surfaces.

## Actual producer and binding checks

Numeric annotations constrain the source signature; they do not prove a Number
producer. Every factory use must resolve to one unchanged lexical declaration
and be an ordinary direct call with actual Number arguments. Complete writer
unions reject opaque or reference assignments, including incompatible writes to
unused callback cells and aliases. Constructor and explicit generic calls refuse
before helper normalization.

Capture initialization remains a separate proof. A typed numeric local may
begin undefined only when an actual Number assignment dominates its Arrow
creation and subsequent writers remain numeric. A later factory assignment to a
callback cell must dominate every read, including alias copies and reflection.
Each callback value read must have one actual initialized numeric callable
producer. Callback declarations with no actual allocation producer remain
refused; this repair does not add uninitialized callback startup semantics.

The source analyzer is shared with Font and Number text lowering and does not
rewrite the AST. Ordinary consumers retain their existing policy. The numeric
factory gate supplies an Arrow invocation-result fact only after validating its
actual body, captures, initialization and immutable factory calls; return
annotations cannot seed it. Structural binary helper facts are checked for each
actual call's operands.

Ninety-one focused pure/native controls pass, including Code, saved-project and
current export/reimport routes. A differential check preserves 406 retained
input AST and diagnostic results for ordinary Font lowering. Independent review
also passes the new source controls and directed refusal cases on the current
composed runtime. No new selected-original execution or hosted GUI qualification
is claimed by this correctness repair. Wider callable types and direct nested
callback-invocation operands remain outside this gate.
