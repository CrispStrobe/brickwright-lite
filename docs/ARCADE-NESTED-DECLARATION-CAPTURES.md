# Arcade nested ordinary declarations with captures

## Bounded first slice

Preserve actual nested `FunctionDeclaration` bodies and lexical bindings through
source conversion, native managed calls, Code/Blocks, saved projects and current
export/reimport. Begin with unchanged, uniquely resolved direct declarations,
concrete primitive parameters and Number results proved from actual callers,
writers and completed returns. Annotations constrain consumers and never supply
producer facts. A spelling, generated name, signature or retained source body is
not authority.

The first implementation may conservatively refuse calls before the nested
declaration's established allocation boundary, captures not initialized there,
escaped/indirect entries, reassignment, ambiguous block declarations, recursive
nested declarations and opaque completion. It must name these refusals. It must
retain the complete executable helper body, its effects and returns. Replacing
it with an Arrow wrapper or substituting its return expression is not support.
Existing module/namespace named labels and numeric factory Arrows stay separate.

## Ownership, storage and completion

Resolve enclosing invocation, exact nested declaration and every captured
binding independently. Use actual all-writer and occurrence initialization
proof; include every caller and possible managed entry. Distinct outer calls
must not share captured mutable storage. Repeated reads in one outer invocation
must identify that invocation's declaration label. Mutable captures retain the
actual cell, including later writes and aliases; immutable captures retain the
value at the qualified allocation boundary. A captured global remains its
actual target binding and cannot borrow a local with the same name.

Reuse the existing managed callable and capture machinery only with an explicit
validated declaration-allocation representation. No source tag may manufacture
a native closure. Bind current target/procedure, exact creation operation,
lexical owner, ordered formals/captures, current body and invocation lifetime.
Validate arguments before body effects and validate actual result completion.
Failure, Stop, load, disposal, stale caller and foreign target cannot settle a
failed invocation as success or revive an old reference. No runtime generation
reset is an acceptable substitute for per-invocation failure cleanup.

Every declaration allocation must bind the real enclosing invocation even when
it captures no local values or reads globals only. A target/procedure label
cache cannot merge distinct enclosing calls. An invented capture used only to
force allocation freshness is not an invocation identity proof.

Use actual frame, local-storage and capture-cell identities, together with the
current operation and lifecycle, to prove the enclosing owner. A procedure name
and runtime generation alone are insufficient. Suspension must retain the right
owner; return, failure, Stop and load cannot authorize a retained dead caller.
The first direct-call slice does not admit an escaped closure after its outer
frame returns.

The declaration representation needs its own actual typed invocation and
completed-return enrollment. An existing untyped capture route or zero-argument
named-label guard does not supply a primitive argument/result certificate.
Keep those paths unchanged. Reprove actual inputs and body completion before
issuing any new private entry or result ticket; a signature is an obligation.

## Current project and authoring

Current export must reconstruct a genuine nested declaration and the current
helper body from connected Blocks, with actual capture/cell identity and caller
proof. It must not embed a declaration as a function expression, restore an old
body, erase a current effect or infer declaration identity from a label prefix.
Validate creation and initialization ordering, all reads/writes, parents,
unique connected inputs and metadata before export. Edited signatures, capture
substitution, hidden extra effects, malformed/current foreign or cyclic graphs
must refuse. Whole-project consistent renaming remains supported.

Retain editable body, argument, local/captured writer and result operations in
Code and Blocks. Track visible declaration creation, capture editing and precise
error-location UX separately if the existing UI cannot author them. Portable
native or pure tests do not qualify those GUI routes.

## Qualification and exclusions

Use independent fixtures with full helper side effects; enclosing Number
parameters; mutable local captures; two outer invocations; nested lexical
shadows; alias identity; repeated calls; initialization and all-writer failures;
current body/argument/capture edits; Code, same/fresh SB3 and export/reimport.
Include stale, foreign, Stop/load/disposal and exceptional completion controls.
Preserve existing refusals and qualify unchanged default lanes separately.

Selected-original source and genuinely edited-export execution require frozen
inputs, actual compiler file equality, emitted observer bindings and the normal
reserved guard protocol. No unchanged successful original is replayed.

Callable arrays, general function-value aliases, recursive nested closures,
default/optional/generic functions, class or SDK reference captures/results,
scene registrations and inherited Sprite semantics are separate until proved.
This lane makes no whole-game, browser, shipped-package or legal-clearance claim.
