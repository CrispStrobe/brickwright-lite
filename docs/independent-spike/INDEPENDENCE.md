# Authorship boundary

The original controller implementer was spawned without inherited conversation
history and received functional contracts and synthetic observations. Restrictions
were instruction-based; the coordinator audited the actual tool calls. This
supports an audited contract-only authorship claim, not OS-enforced isolation.

The later speed-envelope implementer also received only neutral contracts and
synthetic fixtures. Its shell calls were confined by a namespace sandbox without
network or repository access, and actual calls were audited. Neither claim covers
retained hub, arena, protocol, compiler infrastructure or coordinator integration.

Complete operational transcripts, original handoffs, external reference results
and licence evidence are preserved in the [private audit repository](https://github.com/CrispStrobe/brickwright-firmware-private/tree/audit/independent-spike-20260930/audits/independent-spike/).
No claim of complete firmware equivalence or physical accuracy is made.
