# Integration record

The controller is integrated through the virtual hub backend interface. Arena,
Scratch and imported LEGO Python execution share state and simulated time.
The previously optional external firmware runtime, its assets, UI selection,
Code-tab action and build tooling have been retired at the owner's request.

Historical coordinator records and validation receipts were archived before
removal in the [private audit repository](https://github.com/CrispStrobe/brickwright-firmware-private/tree/audit/independent-spike-20260930/audits/independent-spike/).
The public product ships only the independent virtual backend. Removing tracked
files does not erase historical Git objects or previously published artifacts.
